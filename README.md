# Προγραμματισμός Fortran και C σε Windows με WSL, Ubuntu και VS Code

## 1. Εισαγωγή

Το αποθετήριο αυτό περιλαμβάνει οδηγίες για την εγκατάσταση και τη διαμόρφωση ενός περιβάλλοντος προγραμματισμού **Fortran και C** σε Windows, χρησιμοποιώντας το **Windows Subsystem for Linux (WSL)**, το **Ubuntu** και το **Visual Studio Code (VS Code)**.

Το WSL επιτρέπει την εκτέλεση ενός περιβάλλοντος Linux απευθείας στα Windows, χωρίς να απαιτείται ξεχωριστή εγκατάσταση λειτουργικού συστήματος ή δημιουργία εικονικής μηχανής από τον χρήστη.

Με την ολοκλήρωση των παρακάτω βημάτων, θα μπορούμε να γράφουμε, να μεταγλωττίζουμε και να εκτελούμε προγράμματα Fortran και C μέσα από το VS Code, χρησιμοποιώντας τους μεταγλωττιστές του Ubuntu.

## 2. Προαπαιτούμενα

Για την εγκατάσταση χρειαζόμαστε:

- Windows 11 ή συμβατή έκδοση των Windows 10.
- Σύνδεση στο διαδίκτυο.
- Δικαιώματα διαχειριστή (Administrator) για την εγκατάσταση.
- Visual Studio Code.

## 3. Εγκατάσταση WSL και Ubuntu

Ανοίγουμε το **Windows PowerShell** με δικαιώματα διαχειριστή (*Run as Administrator*).

Εκτελούμε την εντολή:

```powershell
wsl --install -d Ubuntu
```

Η εντολή εγκαθιστά το WSL και τη διανομή Ubuntu.

Εφόσον ζητηθεί, επανεκκινούμε τον υπολογιστή.

Κατά την πρώτη εκκίνηση του Ubuntu θα χρειαστεί να δημιουργήσουμε ένα όνομα χρήστη και έναν κωδικό πρόσβασης για το περιβάλλον Linux.

### 3.1 Έλεγχος εγκατάστασης

Ανοίγουμε ξανά το PowerShell και εκτελούμε:

```powershell
wsl --list --verbose
```

Ένα ενδεικτικό αποτέλεσμα είναι:

```text
  NAME       STATE           VERSION
* Ubuntu     Running         2
```

Η ένδειξη `VERSION 2` επιβεβαιώνει ότι το Ubuntu χρησιμοποιεί το WSL 2.

## 4. Ενημέρωση του Ubuntu

Ανοίγουμε το τερματικό του Ubuntu και εκτελούμε:

```bash
sudo apt update
sudo apt upgrade -y
```

Η πρώτη εντολή ενημερώνει τη λίστα των διαθέσιμων πακέτων, ενώ η δεύτερη εγκαθιστά τις διαθέσιμες ενημερώσεις.

Η εντολή `sudo` επιτρέπει την εκτέλεση εντολών με αυξημένα δικαιώματα.

## 5. Εγκατάσταση μεταγλωττιστών Fortran και C

Για τη μεταγλώττιση προγραμμάτων εγκαθιστούμε τα απαραίτητα εργαλεία:

```bash
sudo apt install build-essential gfortran gdb -y
```

Τα βασικά εργαλεία είναι:

| Εργαλείο | Περιγραφή |
|---|---|
| GCC (`gcc`) | Μεταγλωττιστής C |
| GFortran (`gfortran`) | Μεταγλωττιστής Fortran |
| GDB (`gdb`) | Εργαλείο αποσφαλμάτωσης |
| Make (`make`) | Αυτοματοποίηση της διαδικασίας μεταγλώττισης |

Το πακέτο `build-essential` περιλαμβάνει βασικά εργαλεία ανάπτυξης, όπως το GCC και το Make.

### 5.1 Έλεγχος μεταγλωττιστών

Εκτελούμε:

```bash
gcc --version
gfortran --version
gdb --version
```

Εάν η εγκατάσταση έχει ολοκληρωθεί επιτυχώς, εμφανίζονται πληροφορίες για τις εγκατεστημένες εκδόσεις.

## 6. Σύνδεση του Ubuntu με το Visual Studio Code

Εγκαθιστούμε το Visual Studio Code στα Windows από την επίσημη ιστοσελίδα:

https://code.visualstudio.com/

Στη συνέχεια, ανοίγουμε το VS Code και εγκαθιστούμε τις επεκτάσεις:

- **WSL (Microsoft):** Επιτρέπει τη σύνδεση του VS Code με το περιβάλλον Ubuntu.
- **Modern Fortran:** Παρέχει υποστήριξη για τη συγγραφή κώδικα Fortran.
- **C/C++ (Microsoft):** Παρέχει υποστήριξη για τη συγγραφή και την αποσφαλμάτωση κώδικα C/C++.

### 6.1 Δημιουργία φακέλου εργασίας

Ανοίγουμε το τερματικό του Ubuntu και δημιουργούμε έναν φάκελο για τα προγράμματά μας:

```bash
mkdir -p ~/programming
cd ~/programming
```

Έπειτα εκτελούμε:

```bash
code .
```

Το VS Code ανοίγει στον συγκεκριμένο φάκελο, συνδεδεμένο με το Ubuntu μέσω WSL.

Μπορούμε πλέον να χρησιμοποιούμε το ενσωματωμένο τερματικό του VS Code για την εκτέλεση εντολών Linux.

## 7. Δημιουργία και εκτέλεση προγράμματος Fortran

Δημιουργούμε ένα αρχείο με όνομα `hello.f90`.

Προσθέτουμε τον παρακάτω κώδικα:

```fortran
program hello
    implicit none

    print *, "Hello from Fortran!"

end program hello
```

### 7.1 Μεταγλώττιση

Ανοίγουμε το τερματικό του VS Code και εκτελούμε:

```bash
gfortran hello.f90 -o hello
```

Η εντολή μεταγλωττίζει τον πηγαίο κώδικα και δημιουργεί ένα εκτελέσιμο αρχείο με όνομα `hello`.

### 7.2 Εκτέλεση

```bash
./hello
```

Αποτέλεσμα:

```text
 Hello from Fortran!
```

## 8. Δημιουργία και εκτέλεση προγράμματος C

Δημιουργούμε ένα αρχείο με όνομα `hello.c`.

```c
#include <stdio.h>

int main(void)
{
    printf("Hello from C!\n");

    return 0;
}
```

### 8.1 Μεταγλώττιση

```bash
gcc hello.c -o hello_c
```

### 8.2 Εκτέλεση

```bash
./hello_c
```

Αποτέλεσμα:

```text
Hello from C!
```

## 9. Βασικές εντολές Linux

| Εντολή | Περιγραφή |
|---|---|
| `pwd` | Εμφάνιση του τρέχοντος φακέλου |
| `ls` | Εμφάνιση αρχείων και φακέλων |
| `cd` | Μετακίνηση σε διαφορετικό φάκελο |
| `mkdir` | Δημιουργία νέου φακέλου |
| `rm` | Διαγραφή αρχείων |
| `cp` | Αντιγραφή αρχείων |
| `mv` | Μετακίνηση ή μετονομασία αρχείων |
| `gcc` | Μεταγλώττιση προγραμμάτων C |
| `gfortran` | Μεταγλώττιση προγραμμάτων Fortran |
| `code .` | Άνοιγμα του τρέχοντος φακέλου στο VS Code |

**Προσοχή:** Η εντολή `rm` διαγράφει αρχεία χωρίς να τα μεταφέρει απαραίτητα στον κάδο ανακύκλωσης.

## 10. Χρήση του WSL από τα Windows

Μπορούμε να ξεκινήσουμε το Ubuntu απευθείας από το PowerShell:

```powershell
wsl -d Ubuntu
```

Για να εμφανίσουμε τις εγκατεστημένες διανομές Linux:

```powershell
wsl --list --verbose
```

Για να τερματίσουμε όλες τις διανομές WSL:

```powershell
wsl --shutdown
```

Οι παραπάνω εντολές εκτελούνται στο PowerShell των Windows και όχι μέσα στο Ubuntu.
